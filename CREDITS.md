# Credits

This file is the single place for the credits of BlockcraftMC: music, sounds, models, textures, maps, code and
plugins. Its music, sound and model sections also ship inside the resource pack as `credits/CREDITS.md`.

A cell that says "unknown, needs checking" means the repository does not record that fact. The source column names a URL when the repository records one, and
otherwise the place the repository names, such as a Maven module or a backup.

"BlockcraftMC project" means work made for this project. The repository has no licence file for that work, so its
licence is an open question too.
